## 这是什么

**Quant System** 是一个面向 **币安 U 本位永续合约** 的量化交易系统。

Step 1 只做一件事：**用 3 分钟 K 线做趋势跟踪，吃“突破 + 趋势骑行”这一段**。

它做这些事：

- 用交易所的 kline 流作为 K 线权威源
- 三个因子（动量 / 订单簿失衡 / 成交量）加权合成趋势评分
- 状态机四个状态：`IDLE → BREAKOUT_CONFIRM → TREND_RIDE → TOP_DETECT`
- 三根 K 线确认突破，防假信号
- 服务器端止损单保护持仓
- 一轮一轮地管理，每轮完整归因

它**不做**这些事（推迟到 Step 2/3/4）：

- ❌ 加仓 / 反向做单 / 分批止盈
- ❌ 网格 / 调度器
- ❌ 多品种 / 相关性管理
- ❌ AI 参数自适应
- ❌ 双机热备 / 托管部署

**为什么只做这些**：Step 1 的目标不是“赚钱”，是**跑通闭环、系统层干净、每一笔都能回放**。贪多做全，死得快。
