# ============================================================================
# requirements.txt — Quant System Step 1 依赖锁（小白友好版）
# ============================================================================
#
# 安装前必读：
#   1. 确保 Python 版本是 3.11 或 3.12（不要用 3.13，numpy 1.26.4 无 wheel）
#   2. 激活虚拟环境后再执行 pip install（详见 DEPLOY 文档）
#   3. 如果下载慢，使用国内镜像：
#      pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# 版本策略：
#   所有依赖用 == 精确锁定，避免“在我机器上能跑”的版本漂移。
#
# 已知钉子（不要随意升级）：
#   - websockets==12.0：代码用了 websockets.sync.client，12.0 才引入。
#     13.x 的 recv() 签名有变，升级会崩。不能降级。
#   - numpy==1.26.4：1.x 的最后稳定系列。2.x 有 breaking change，不要升。
#   - pydantic==2.5.3：与 fastapi 0.109.0 严格配套。升 3.x 会破坏兼容性。
# ============================================================================
